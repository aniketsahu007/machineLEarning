# machineLEarning

A beginner-friendly repository containing simple machine learning notebook examples.

## Contents

- `linear regression/`
  - `Untitled.ipynb`
  - `Untitled1.ipynb`
  - `insurance.csv`
- `logistic regression/`
  - `logisticRegression.ipynb`
  - `heart.csv`

## Getting Started

1. Clone the repository.
2. Create and activate a Python virtual environment (recommended).
3. Install Jupyter and common ML dependencies:
   - `pip install jupyter notebook pandas numpy scikit-learn matplotlib`
4. Start Jupyter:
   - `jupyter notebook`
5. Open and run notebooks from the `linear regression` or `logistic regression` folders.

## Notes

- Datasets used by notebooks are stored alongside each notebook.
- Notebook file names can be renamed to more descriptive names as the project evolves.
